# Créditos y licencias de imágenes

Todas las fotografías del sitio son de **licencia libre para uso comercial**,
verificable. Se eligieron bajo **CC0 / dominio público** (sin obligación de
atribución y con permiso de modificación), por lo que se les aplica un tratamiento
de duotono teal para armonizar con la marca. No se usan fotos de stock sin licencia
ni imágenes con texto en inglés.

|---|---|---|---|
| `datacenter.jpg` | Proceso (imagen enmarcada) | Wikimedia Commons — "Front of server racks at NERSC" | CC0 / dominio público |
| `soporte.jpg` | Nosotros (foto principal) | StockSnap.io — "Laptop Working" | CC0 (StockSnap) |

Descubrimiento vía Openverse (`api.openverse.org`), filtrando a licencias de uso
comercial (CC0/PDM). La licencia CC0 no exige crédito; este archivo se mantiene
como registro interno para trazabilidad.
